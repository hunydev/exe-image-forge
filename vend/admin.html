자격증명 상태

서비스상태만료계정

행을 클릭하면 아래 터미널에 로그인 명령이 입력됩니다. 액세스 토큰 만료는 refresh 토큰이 있으므로 CLI가 첫 실행 시 자동 갱신합니다 — 보통 조치가 필요 없습니다.

터미널

이미지 안에서 실행됩니다. 여기서 로그인하면 자격증명이 영속 HOME에 저장됩니다. 아래 버튼은 모두 localhost 리다이렉트를 회피하는 방식을 사용합니다.

Gemini 콜백 릴레이 — “localhost 연결 안됨” 화면이 나오면 여기에 붙여넣으세요

Gemini CLI 만 device code 방식이 없어서, 로그인 마지막에 http://localhost:<포트>/oauth2callback?... 로 리다이렉트됩니다. 그 포트는 이 VM 안에 있으니 노트북 브라우저에서는 연결이 실패합니다. 주소창 URL 을 그대로 복사해 넣으면 VM 안에서 대신 요청합니다.

도구 버전

VM 안에서는 ai-cli-update.timer 가 부팅 3분 후 + 매일 자동 업데이트하고, 이 서버는 매주 일요일 hunyimg refresh 로 이미지를 다시 굽습니다.
